01 / ABOUT

什么是 Aisling？

原版增强 · 永不开荒重置 · 永不关服

Aisling 是一个由 Tu_village head 维护，自 2023 年 8 月 3 日开放的私人性质服务器。

04 / GET STARTED

三步上手

从进群到定居，十分钟搞定。

① 加入官方 QQ 群

群内发布更新公告与服务器动态。群号 543231701，进群问题填写「文档」。 详见 加入服务器

② 获取服务器 IP 并连接

使用 Java 版 加入（推荐）。IP 因安全需要不定期更换，进群获取；版本需与服务器匹配。 自 2nd+ 起不再支持跨版本，如需请自行使用 ViaFabric Plus 模组。

③ 阅读文档 → 离开主城区 → 建立城镇

建议先读完 玩家守则 与 模组规则， 再按 基本指令 → 创建城镇 的顺序推进。

connection.sh — aisling
join-qq-group 543231701
> 验证问题：文档
> [OK] 已进入群聊，公告区可查看最新 IP
connect <server-ip>
> Java Edition · 版本需匹配
> [OK] 连接成功，欢迎来到 Aisling
