常见问题解答

入服

服务器 IP 是多少？

出于安全需要并会不定期变换，IP 不公开，进群获取。QQ 群：543231701，进群问题填「文档」即可。详见「加入服务器」。

需要什么版本？

请使用与服务器匹配的版本，当前版本为 26.1.2。自 2nd+ 起不再支持跨版本；确有需要可自行使用 ViaFabric Plus，但部分功能可能受限。建议用最新客户端以获得最佳体验。

手机 / 基岩版能玩吗？

本服基于 Fabric（Java 版）。基岩版账号绑定 Java 版账号的教程见「效率工具」；是否支持基岩版直连，以群公告为准。

有白名单吗？

有。严重违反群聊守则者会被撤销服务器白名单或封禁，详见「玩家守则」。

进服之后

我在一个空荡荡的地方，怎么出去？

那是主城的空置域，尚未完工。找到名叫「传送点」的 NPC，右键打开 GUI，选一个出城传送点即可；也可以徒步跑到边缘坐水电梯上去。详见「熟悉基本指令及离开主城区」。

死亡后东西掉了，能找回来吗？

本服未开启保留物品栏，死亡时物品会掉落在地上。请立刻用 /dback或 /back 返回死亡点（越早回去，物品越安全）。服务器不提供人工恢复物品。

怎么保护我的家和城镇？

用领地。本服使用的是国产插件 Dominion（不是 Residence），官方玩家手册写得很详细，直接去查最靠谱——入口见「防护系统」。另外服务器的 CoreProtect 类记录可用于回溯破坏行为。

游玩与生活

日活不高，服务器会关服吗？

不会。服务器于 2023 年 8 月 3 日开放，已稳定运行 3 年；服主明确说过「无论如何，本服务器永不关服」。不过服主一人总揽全局，上学期间可能停更。

这里有哪些玩法？

核心是城镇建造与抵御、反击凋灵入侵，另有生存系、探险系、PVE 系、全典系、商贾系等玩法分类；整体偏原版、轻度 RPG，没有副本与小游戏，见「服务器介绍」。

硬币怎么获得？有什么用？

新手礼包会给 1000 硬币，其余获取方式（反馈 bug、提建议、投稿宣传视频）见「快速薅羊毛/圈钱教程」；经济与交易系统尚在建设中，详见「经济与交易」。

延迟很高、老是掉线怎么办？

依次尝试：使用电信网络 → 用移动数据（实测 1 小时约 50 MB）→ 装 Krypton → 装 Raknetify 并在地址前加 raknet; 前缀。完整说明见「关于服务器网络」。

社群与规则

能开小号吗？

不允许用小号获取不正当利益；也不能用甩锅、换账号等方式逃避处罚，详见「玩家守则」。

能在群里宣传其他服务器吗？

同性质服务器（例如其他生存服）不行；知名服务器（如 2b2t）、PVP 服与小游戏服、Minecraft 官方活动服务器与 Realms、基岩版服务器、个人联机则是允许的。

发现 bug 或想提建议怎么办？

私信服主。有效 bug 每条 500-5000 硬币，建议每条 500-2000 硬币；用漏洞前先上报，比用了被封划算。

怎么加入 Member 权限组？

见「加入 Member 权限组」。它可以使用假人、语音聊天等高级功能，定位类似于审核制内服，要求大致是：和服主及群友熟、有实力、有技术。目前服务器未做权限组分类。

我能当管理、运营或者建筑师吗？

可以，而且很需要人手——目前管理团队只有服主一人（群管理员不参与运营）。见「成为游戏内管理/运营/建筑师等」。

有疑问该找谁？

优先在 QQ 群（543231701）里问，群友和文档通常能解决大部分问题；需要服主处理的事（举报、申诉、bug、赞助、权限）请私信服主。服主很忙，响应不及时属正常现象，请耐心一些。
