规则与基础07

熟悉基本指令及离开主城区

开始之前

服务器的大部分功能都集中在菜单里：进服后你会自动获得一个时钟物品，右键点击，或者直接在聊天框输入 /menu，即可打开服务器菜单。

小提示：按下 T 键打开聊天框后，聊天框里的文字或许是可点击的，很多提示都能直接点开。

菜单底部导航栏可以切换：主页 / 功能 / 世界传送 / 等级 / 领地 / 城镇 / 技能与强化。更多菜单说明见「基础功能」。

常用指令速查

家（Home）

  • /home set 名字　在脚下设置一个家
  • /home tp 名字　传送到这个家
  • /home　传送到第一个家
  • /home list　列出你所有的家
  • /home gui　用图形界面管理

也可以打开 菜单 → 功能 → 家，一键进入管理界面。

玩家传送（TPA）

  • /tpa 玩家名　请求传送到对方那里
  • /tpahere 玩家名　请求对方传送到你这里
  • /tpaccept / /tpadeny　接受 / 拒绝（加 all 可批量处理）
  • /tpacancel　取消你发出的请求

返回与死亡点

本服未开启保留物品栏，死亡会掉落物品，请第一时间赶回死亡点。

  • /dback　死亡后返回死亡点
  • /back　回到上一个位置（死亡、传送后都能用）
  • /back list　查看历史位置记录

死亡和传送都会自动记录；32 格以内的短距离移动不记录，最多保存 3 个历史位置。

探索与其它

  • /rtp　随机传送到世界某处，适合探索和找新地盘（滥用会受到限制）
  • /pvp on | off | status | list　PvP 开关，双方都开启才能互相伤害
  • /sit　随时随地坐下休息，移动即站起
  • /rank progress　查看称号升级进度；/rank list all-rank-nodes　查看全部称号

离开主城区（空置域）

出生点位于主城的空置域。空置域尚未完工，请不要长期停留、建造或堆放物品。

  • 找到名叫「传送点」的 NPC，右键打开 GUI，选择一个出城传送点即可离开。
  • 也可以徒步跑到空置域边缘，坐水电梯上到陆地。

主城的更多说明见「关于主城」；若有意协助空置域建设，欢迎随时联系服主。
