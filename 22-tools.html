效率工具

这一页包括什么

本页汇总「让重复劳动变少」的一类功能，原文提到的是：连锁挖矿、效率类附魔，以及基岩版绑定 Java 版账号的教程——因为绑定一次、永久生效，省去了每次登录时的时间。

关于基岩版绑定

绑定一次即永久生效，适合同时玩基岩版与 Java 版、又不想反复登录的玩家。另外，自 2nd+ 开始不再支持跨版本：需要跨版本的玩家请自行使用 ViaFabric Plus 模组，详见「连接到服务器」。

进服就能用的效率功能

服务器菜单（进服后自动获得的时钟物品，右键点击或输入 /menu）里已经内置了一批省事的功能：

  • 快捷工具（菜单 → 功能 → 快捷工具）：可以在任何地方打开工作台、末影箱、铁砧、切石机、砂轮、织布机、制图台、锻造台。
  • 拆解台：菜单 → 功能。
  • 家：/home set 名字 设点、/home tp 名字 传送、/home list 列表、/home gui 图形管理。
  • 返回与随机传送：/back 回到上一位置（32 格以内的移动不记录，最多保存 3 个历史位置）；/rtp 随机传送到世界某处。
  • 玩家传送：/tpa、/tpahere、/tpaccept（可用 /tpaccept all）。

完整指令表见「基础指令」，菜单结构见「基础功能」。
