功能与系统19

基础功能

这里将会介绍菜单、基础指令等，按照使用频率和新人接触顺序排序。以下内容围绕菜单模组和Fuji 模组展开。

小提示：按下T 键后，聊天框内的文字或许可以点击。

菜单

进服后你会自动获得一个时钟物品，右键点击或输入 /menu 即可打开服务器菜单。

（菜单图）

菜单底部导航栏可以切换不同页面：
主页 —— 查看个人信息、签到、服务器数据
功能 —— 家、快捷工具、拆解台
世界传送 —— 跨世界传送，可快速前往主世界、下界、末地等。
等级 —— 等级系统
领地 —— 领地管理
城镇 —— 城镇系统
技能与强化 —— 技能强化

家

设置传送点，随时传送回家。

/home set 名字 在脚下设置一个家

/home tp 名字 传送到这个家

/home 传送到第一个家

/home list 列出你所有的家

/home gui 用图形界面管理

也可以打开菜单 → 功能 → 家，一键打开管理界面。

玩家传送（TPA）

传送到朋友身边或邀请朋友过来。

/tpa 玩家名 请求传送到对方那里

/tpahere 玩家名 请求对方传送到你这里
/tpaccept 玩家名 接受

/tpadeny 玩家名 拒绝

/tpacancel 玩家名 取消你发出的请求

也可以 /tpaccept all 一键接受所有请求，/tpadeny all 全部拒绝。

返回上一个位置（Back）

死后 / 传送后快速返回原地。

/back 回到上一个位置
/back list 查看历史位置记录

死亡和传送都会自动记录。32格以内的短距离移动不记录。最多保存3个历史位置。

随机传送（rtp）

随机传送到世界某处，适合探索和找新地盘。滥用此功能会受到限制。

/rtp 没错，就这一条

快捷工具

菜单 → 功能 → 快捷工具，可以在任何地方使用这些方块：工作台、末影箱、铁砧、切石机、砂轮、织布机、制图台、锻造台。

PvP开关

自行决定是否参与战斗，双方都开PvP才能互相伤害。

/pvp on 允许和其他开PvP的玩家战斗

/pvp off 关闭PvP

/pvp status 查看自己状态

/pvp list 看谁开了PvP

十二、称号升级（Rank）

完成条件后升级称号。

/rank progress 查看升级进度

/rank up 称号名 --confirm true 升级

/rank down 称号名 --confirm true 降级

/rank list all-rank-nodes 看所有称号

/rank info 称号名 看详情

降级后需重新满足条件才能再升级。

八、坐下（Sit）

随时随地坐下休息。

/sit

移动即站起。
