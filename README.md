# Aisling wiki

Minecraft 服务器 **Aisling** 的文档站点，共 **30 个页面**。

- 🌐 在线浏览：https://huoxingrnana.github.io/aisling-wiki/
- ✍️ 原文档作者：**Tu_village head**
- 📅 服务器自 2023 年 8 月 3 日开放，当前版本 2nd+，QQ 群 **543231701**

## 这个版本做了什么

| 项目 | 说明 |
|---|---|
| 图片本地化 | 36 张原外链图片全部下载并压缩为 WebP（57 MB → 约 3.3 MB），断网可看 |
| 排版重构 | 统一配色与字号、标题层级、表格与代码样式；页脚仅保留署名 |
| 移动端适配 | 抽屉式侧栏 + 遮罩关闭、目录实时筛选、深色模式、阅读进度条、上一页/下一页 |
| 内容补写 | 15 个原先空白或只有一句话的页面补写了正文，全部取自站内已有信息 |
| 界面装饰 | 分板块配色（7 套色系）、页面顶部章节封条、侧栏分组、标题编号徽章 |

## 本地使用

直接打开根目录的 `index.html` 即可，无需服务器、无需联网。
`assets/` 下是共享的样式与脚本，改一处 30 页同时生效。
