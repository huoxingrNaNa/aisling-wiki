【界面装饰层】
为让页面不那么单调，assets/wiki.css 末尾追加了一层纯 CSS 装饰（明暗主题自动跟随）：
- 顶栏：三段渐变 + 顶部高光线，品牌名前加小方块标记
- 侧栏：顶部主题淡染、标题下短线、选中项左侧主题色条、悬停轻微位移
- 正文：整体卡片化（圆角 + 投影 + 顶部主题色细线），载入时轻微上浮
- 标题：二级标题自动编号徽章（01、02…）+ 渐变底线；三级标题配菱形标记
- 文本：链接下划线自左铺开、加粗文字淡色高亮、列表用主题色圆点、代码行内胶囊
- 交互：图片悬停微浮、翻页卡片投影、回到顶部主题渐变按钮、滚动条美化
- 打印：自动隐藏全部装饰与背景，省墨；系统开启「减弱动态效果」时动效自动关闭

【分板块配色】
整站按内容分成 6 个板块，每个板块一套主题色（顶栏、标题徽章、侧栏淡染、按钮、封条同步变化）：

| 板块 | 页面 | 主题色 |
|---|---|---|
| 主页 | index | 蓝 |
| 简介与加入 | 02 03 04 | 靛蓝 |
| 规则与基础 | 05 06 07 | 红 |
| 城镇与探索 | 08~13 | 青绿 |
| 玩法分类 | 14~18 | 紫 |
| 功能与系统 | 19~24 | 橙 |
| 新人·社群与参与 | 25~30 | 玫红 |

每页顶部新增「章节封条」：左侧板块名、右侧页面编号，配色即该板块主题色（带像素纹理）。
左侧目录新增 6 个分组标题，搜索时会自动隐藏没有匹配项的分组。

想改回全站统一配色：删除 assets/wiki.css 中 /* ===== 分板块配色 ===== */ 这一段即可，
所有页面会自动回落到 :root 的默认蓝。

回滚方式：删除 assets/wiki.css 中 /* ==== 装饰层 … ==== */ 到 /* ==== 装饰层结束 ==== */ 整段即可；
或在 /root/wiki_build 下依次运行 python3 decorate.py（重建装饰层）。
